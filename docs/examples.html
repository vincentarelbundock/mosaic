Examples

This page hosts eight complete slide decks: four are built on one of Mosaic’s bundled themes, some leaning on the themes’ own layouts and others hand-crafting every slide from named cells and custom palettes, and the last four define a theme of their own to re-create an outside design. Click a thumbnail to page through its slides. The GitHub repository contains every deck’s full Typst source, assets, Makefile, and compiled PDF.

Start with the tutorials
These are complete, fairly intricate decks: they combine custom palettes, hand-built grids, and theme extensions, so their source is not the gentlest introduction to Mosaic. If you are new to the package, read Get started first, then the guides on writing slides and themes and colors. The code below reads much more easily afterwards.
